# learning-experiment-task
卒業研究用・実験タスクシステム（プロトタイプ）

## 概要
学習課題遂行中の生体情報・操作ログ計測に向けた実験タスク提示システムの仮実装です。

## 画面・機能構成（現在：プロトタイプ版）
- **スタート画面**: 被験者の名前・学籍番号の入力・確認
- **タスク画面**:
  - **画面上部**: 課題文章の提示、マーカー・下線ツール
  - **画面下部**: 問題文・属性ラベルの提示、回答入力欄、提出ボタン
  - **画面右端**: 自由記述のメモ欄
- **実験終了画面**: 全問回答後に遷移（簡易ログデータのプレビュー機能付き）

## ファイル構成
- `index.html`: 画面レイアウトの定義
- `style.css`: スタイル・3分割レイアウトの定義
- `questions.js`: 問題リストデータ（文章・問題文・模範解答・属性のセット）
- `app.js`: 画面遷移、マーカー・下線機能、仮データの記録処理

## 起動方法
`index.html` をブラウザ（Google Chrome / Safari など）で開くだけで動作します。
